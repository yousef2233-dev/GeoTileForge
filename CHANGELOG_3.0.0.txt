## [3.0.0] - 2025-11-17
### Rebranded & Redesigned
- Renamed to GoogleTileForge Pro: Enhanced branding for better market appeal and professional identity
- Download Manager Interface: Complete UI overhaul inspired by Internet Download Manager (IDM) for intuitive user experience
- Modern Control Panel: Added execution mode selector (Sequential/Parallel) with visual indicators for running tasks and queue status
### Download Management System
- Multi-Task Support: Download multiple KMZ/KML files simultaneously with intelligent queue management
- Parallel Downloads: Support for up to 4 concurrent tile download tasks with configurable worker threads (1-4 per task)
- Sequential Mode: Process multiple tasks one-by-one for resource-constrained systems
- Queue Priority Control: Reorder tasks with Move Up/Down/Top/Bottom functions for flexible workflow management
### Task Control & Monitoring
- Advanced Task States: Added Idle, Downloading, Paused, Stopped, Completed, Partially Completed, and Error states
- Pause & Resume: Pause downloads and resume from exact point with timestamp-based session recovery
### Persistent Session Management
- Auto-save System: Automatic task history saving every 60 seconds plus save-on-exit for crash protection
- Session Recovery: Automatically restore all tasks with their progress on application restart
- Smart State Conversion: Running downloads automatically converted to "Paused" state on restart
### Enhanced Download Engine
- Abort Mechanism: Threading.Event-based abort system for clean task termination
- Verification System: Post-download tile validation with black-pixel detection and file integrity checks
- Failed Tile Retry: Automatic retry pass for failed tiles with adjustable retry counts
### Custom Tile URL Support
- Tile Manager Integration: Add custom tile servers through built-in tile URL manager
### File Management
- Multi-file Selection: Add multiple KMZ/KML files at once for batch processing
- Smart Folder Validation: Automatic output folder creation and validation on resume
- Folder Check on Resume: Prompts user to select new folder if original doesn't exist
- Pickle-based Storage: Robust task persistence with version handling for backwards compatibility
### Developer Improvements
- Thread-safe Operations: Proper threading.Event usage for clean shutdown and pause
- **Callback System: Flexible callback mechanism for sequential task chaining
### Improved
- Memory Efficiency: Optimized tile downloading with streaming and cleanup
- Network Reliability: Enhanced retry logic with exponential backoff
- Progress Accuracy: Real-time tile counting with downloaded/total display
- Performance: Multi-threaded downloads with configurable worker pools
### Fixed
- Memory Leaks: Proper cleanup of threading objects and file handles
- UI Freezing: All long-running operations moved to background threads
- Session Recovery: Fixed iid conflicts and state restoration issues

## [1.5.0] - 2025-02-14
### Added
- Output Control: Implemented "Verify Downloaded Tiles" checkbox to ensure the quality of downloaded image tiles via 2 steps check.
-- Step 1: Check if the file size is not below a given threshold.
-- Step 2: If the file size is below the threshold, check if the image is not mostly black using the function.
-- If the tile is invalid (mostly black and small), it deletes the file, increments the retry count, and if the retry count is less than the allowed number of retries, it logs a message and retries downloading the tile after a delay.
